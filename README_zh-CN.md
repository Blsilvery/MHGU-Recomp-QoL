# MHGU Recomp QoL

为 **《怪物猎人 XX 世代终极版 Recompiled》（MHGU Recomp）** 提供便利功能的 Forge 插件。它可以加快采集、简化任务缴纳和报酬收取，并提供可单独开关的狩猎辅助选项。

**当前版本：** v1.16.2 · 模组兼容版

[下载 v1.16.2 完整安装包](https://github.com/Blsilvery/MHGU-Recomp-QoL/releases/download/v1.16.2-mod-compatibility/MHGU_Recomp_QoL_v1.16.2_Mod_Compatibility.zip) · [查看全部版本](https://github.com/Blsilvery/MHGU-Recomp-QoL/releases) · [English](README.md)

> **运行要求：** MHGU Recomp，游戏版本 1.4.0。

## 安装

1. 点击上方链接下载完整 ZIP。
2. 完全退出 MHGU Recomp，然后解压 ZIP。
3. 将包内的 `mods` 文件夹复制或合并到 MHGU Recomp 游戏目录；遇到同名文件时选择覆盖。
4. 启动游戏，按 **Insert** 打开 Forge，再进入 **MHGU Recomp QoL** 设置。

此 ZIP 是可直接安装的完整包，包含插件以及新增游戏菜单选项所需的菜单资源。初次安装请使用整个压缩包，不要只复制 `.nro` 文件。本仓库中的源码供开发使用；玩家请下载 Release 完整安装包。

更新时同样先退出游戏，再解压并合并 `mods` 文件夹。不需要另外安装 Switch 版 mod 加载器。

## 功能

### 采集与移动

- **免工具采集：** 不携带镐子和虫网也能采矿、捕虫。
- **一次完成采集或剥取：** 与采集点互动一次即可处理该点剩余次数。若想一次只采集或剥取一个，互动时按住手柄右肩键 R 再按 A。
- **调整采集速度：** 范围 1.00～4.00 倍，默认 1.50 倍。
- **调整未被发现时的冲刺：** 冲刺速度范围 1.00～2.00 倍，默认 1.20 倍；耐力消耗可设为原版的 0%～100%，默认 0%。这两项只在大型怪物尚未发现猎人时生效。
- 道具袋装满后批量采集会停止；不会增加道具袋容量，也不会绕过原版道具数量和特殊采集规则。

### 任务缴纳与精算道具

- **任务目标自动缴纳：** 采集到一个任务目标道具，就立即缴纳一个并计入目标数量。超过目标所需数量的同种道具会留在道具袋。
- **副任务自动缴纳：** 开启后，要求缴纳指定道具的副任务会在采集时自动累计进度。
- **其他精算道具自动结算：** 非任务目标的精算道具采到后会立即换算成精算点数。如果还要留着精算道具调合，可先关闭这一项。
- **道具袋手动缴纳：** 任务中按手柄 Y 一键缴纳所有符合条件的道具；选中某个道具后按 A，可单独缴纳该道具。此功能有独立开关，不依赖自动缴纳。
- 自动缴纳沿用游戏原本的任务进度流程，适用于单人和多人任务。

开启 **Put transport items in the item pouch** 后，蛋、火药岩等符合条件的搬运物品会进入道具袋，而不是进入搬运状态；自动缴纳会跳过这些搬运物品。关闭该选项即可按原版方式搬运。

### 报酬、道具箱和其他便利功能

- 在营地通过快递猫打开完整道具箱。出发前，在村庄或集会所调查道具箱，按 A 打开完整道具箱，按住 R 再按 A 打开猫猫看板。任务中在营地快递猫处按 A 或 R + A 都会打开完整道具箱。
- 将任务报酬和鉴定结果全部送入道具箱、一次收取农场三辆交易车的产物，或将猫猫探险队报酬全部入箱。道具箱装满时，剩余物品会保留在收取界面，不会被出售或丢弃。
- 忽略环境寒冷和炎热影响，无需冷热饮。
- 艾露猫干劲保持在 99。
- 道具调合成功率设为 100%。
- 常显地图和大型怪物标记；所有狩猎风格均可装备三个狩技。
- 可关闭的任务快捷键：**Start（＋）+ 十字键下**完成当前任务；**Select（－）+ 十字键上**跳过任务结束等待。可在 Forge 中关闭这些快捷键。

任务报酬、农场和猫猫探险队新增菜单项支持游戏的七种资源语言：英语、法语、西班牙语、德语、意大利语、繁体中文和简体中文。Forge 设置菜单目前为英文。

## 游戏内设置

按 **Insert** → **MHGU Recomp QoL**。主面板提供独立开关，相关设置分组放在二级菜单中：

- **Movement and gathering speed** — 采集速度、冲刺速度和冲刺耐力。
- **Automatic quest delivery** — 主任务目标、副任务目标和其他精算道具。
- **Map, Hunter Arts and quest shortcuts** — 地图与怪物标记、狩技和任务快捷键。

自动缴纳和道具袋手动缴纳是两个独立选项，各项功能也可以分别关闭。

设置会自动保存：修改开关或滑条后稍等片刻，插件就会把设置写入游戏目录下的 `mhgu_recomp_qol.ini`（和 `mhgurecomp.ini` 在同一文件夹），下次启动游戏时自动读取。面板最后一行会显示设置是否已读取或保存。想恢复默认值，先退出游戏，再删除 `mhgu_recomp_qol.ini`。保存设置不会改动游戏存档。

## 兼容性

本插件可以和挂接同一游戏函数的其他 Forge 插件（例如 Faster Field Hunter）一起使用，不受加载顺序影响。两个 mod 改动同一项内容时，效果可能会叠加，请在其中一个 mod 里关闭对应选项。如果作弊码或补丁改动了本插件需要的游戏函数，只会关闭用到它的那一项功能，`log.txt` 会记录具体地址。

## 操作说明

- **一次采集/剥取一个：** 在采集点互动时按住手柄右肩键 R 再按 A，即可临时只执行一次，不进行整批采集。这里的 R 指手柄肩键，不是键盘上的 R 字母。
- **打开猫猫看板：** 出发前在村庄或集会所的道具箱处按住 R 再按 A。单按 A 打开完整道具箱。任务中在营地快递猫处按 A 或 R + A 都打开完整道具箱。
- **手动缴纳：** 任务中打开道具袋，按手柄 Y 一次缴纳所有符合条件的道具；选中一件道具后按 A，只缴纳该件。需要在 Forge 中开启 **Deliver from the Item Pouch anywhere**；它与自动缴纳开关独立。
- **缴纳搬运道具：** 自动缴纳会跳过搬运道具。若搬运道具已放入道具袋，可使用上述手动缴纳操作上交；是否符合缴纳条件仍遵循游戏原本规则。

适用于 MHGU Recomp，游戏版本 1.4.0（也就是 MHGU Recomp 支持的版本）。
