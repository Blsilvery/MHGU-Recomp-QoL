探险队功能的用法：
进入探险队报酬界面，在“送往道具箱”下方选择“全部入箱”并确认。
所有报酬处理完后正常结束该收取阶段；箱子满时保留未收取的报酬。
某叠物品只收取了一部分时，余下的数量仍保留，腾出空间后可以再收取。

农场功能的用法：
交易窗口 -> 收取 -> 全部入箱 -> 按 A 确认。
该选项位于原“送入道具箱”下方，一次处理三辆交易车的已产出物品。
全部收完后返回交易窗口；仍可继续正常委托交易。
某叠物品放不下时整叠留在收取列表，其他能放下的物品继续入箱。
有剩余物品时停留在收取界面，不自动卖出或丢弃；腾出空间后可再次收取。

奖励功能的用法：
完成任务后，在原来的“送入道具箱”下方选择“全部入箱”并确认。
当前页的奖励会送入箱子，然后进入下一页/结束该阶段。
多页奖励仍需每页选择一次。
鉴定出的素材放入道具箱，护石等装备放入装备箱。
箱子装不下时，剩余奖励保留在界面，不自动卖出或丢弃，也不自动退出。
